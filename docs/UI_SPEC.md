# UI Specification

Design intent: **an AutoCAD drafter finds everything where they expect it; everyone else sees a modern, fast, beautiful tool.** Structure and names come from AutoCAD; execution (icons, spacing, motion, theming, responsiveness) is ours.

## 1. Shell layout

```
┌ Title bar: [OET home] Triya CAD 2D  v1.0 (badge) ─── doc tabs ─── [Report issue] [Settings] ┐
├ Ribbon tabs: Home · Insert · Annotate · Parametric · View · Output · Layout · Tools         │
├ Ribbon panels (responsive, see §3)                                                           │
├─────────────────────────────────────────────────────────┬─────────────────────────────────┤
│                                                         │ Palette stack (dockable)        │
│  Canvas (OffscreenCanvas)                               │  Properties                      │
│  + transient layer                                      │  Layers                          │
│  + Dynamic Input overlay                                │  Blocks / Library                │
│                                                         │  References                      │
│                                                         │  Constraints · Compare · Health  │
├ Model | Layout1 | Layout2 | +  ────────── command line (2 lines, expandable, F2 window) ─────┤
├ Status bar: X,Y,Z · SNAP GRID ORTHO POLAR OSNAP OTRACK DYN LWT TPY QP SC · MODEL/PAPER · 1:10 ▾ · ⚙ ┤
```

- Canvas always wins space. Palettes dock right by default; can float, auto-hide, or dock left/bottom; layout persisted locally.
- Document tabs behave like AutoCAD file tabs (hover preview, close, dirty dot, drag to reorder). Resting the mouse on a tab for 400 ms previews the drawing's Model and layouts (each as last drawn; a space not yet shown is pictured as it would open, by a canvas made only for the picture), resting on a thumbnail shows that drawing and space in the drawing area until the pointer leaves the preview (which brings back what showed before), and clicking one keeps it; Ctrl+Shift+Page Up/Down moves the focused tab. A tab shows a dot after its name while the drawing has unsaved changes (not part of the tab's accessible name); closing it, CLOSE, or leaving the page then asks first, in AutoCAD's message box: "Save changes to <name>?" with Yes (focused), No and Cancel, Esc cancelling. Save and Save As… sit in the title bar (Ctrl+S, Ctrl+Shift+S); a save reports "Saved <name>." in a status notice for 4 s. *As built (M2-57):* that notice and "Opening <name>…" float at the top centre of the drawing area, over the drawing, instead of pushing it down, so the canvas keeps its size (and the view its height) while they come and go; only their Dismiss button takes the pointer.
- Layout tabs sit above the command line; `+` creates a layout; right-click for layout commands.
- *As built (M2-23):* after Open, Save, Save As… and Plot… the title bar's Quick Access part has Undo and Redo, which run U and REDO on the drawing shown (Ctrl+Z, Ctrl+Y; Cmd+Shift+Z on a Mac), each greyed out with nothing to undo or redo and titled with the step it would take back or put back ("Undo LINE (Ctrl+Z)"). Ctrl+Z and Ctrl+Y undo typed text instead wherever text is typed, except an empty command line; in the middle of a command they cancel it first, as a ribbon button does. Each undo or redo shows a toast over the drawing for 2.5 s with what it did and how many steps are left ("Undone: LINE · 3 more to undo", "Undone: 3 steps", "Redone: LINE"). *As built (M2-36):* a ▾ beside Undo and beside Redo opens its drop-down list: the steps by name, newest first for Undo and next first for Redo (at most the newest 100; UNDO n reaches further). Pointing at an entry marks it and every entry above it and the foot says "Undo 3 steps"; picking it undoes or redoes them all as one UNDO n or MREDO n. Arrow keys, Home and End move, Enter picks, Esc or a click elsewhere closes the list.
- *As built (M2-19):* beside the version badge the title bar shows the offline status once the service worker runs (`Saving for offline… n%`, then `Ready offline` in green, `Working offline` with no connection), and an Install button before Settings while the browser would install the app. A new version shows a banner under the title bar, "A new version of Triya CAD 2D is ready. Reload to use it; drawings with unsaved changes ask first.", with Reload and Later; nothing reloads until Reload is pressed.

## 2. Ribbon content (tabs → panels → items)

Panel names and groupings match AutoCAD so the drafter's spatial memory transfers. Items are the commands in `COMMANDS.md` by tier.

**Home:** Draw (Line, Polyline, Circle▾, Arc▾, Rectangle▾, Ellipse▾, Hatch▾, Spline▾, Xline/Ray, Point▾, Revcloud▾, Wipeout, Region/Boundary) · Modify (Move, Copy, Stretch, Rotate, Mirror, Scale, Trim▾, Extend, Fillet▾, Chamfer, Array▾, Offset, Explode, Erase, Break▾, Join, Lengthen, Align, Overkill) · Annotation (Text▾, Dimension▾, Leader▾, Table, Centerline▾) · Layers (Layer Properties, layer dropdown, tool row) · Block (Insert▾, Create, Edit, Edit Attributes▾) · Properties (Match Properties, colour/linetype/lineweight/transparency dropdowns, Properties palette) · Groups · Utilities (Measure▾, Quick Select, ID, List) · Clipboard

**Insert:** Block (Insert, Edit Attribute, Create Block, Define Attributes, Manage Attributes, Block Editor) · Reference (Attach, Clip, Adjust, Xref palette, Bind) · Library (PV symbols, Weld symbols, GD&T) · Import (PDF underlay) · Data (Field) · Linking (none; Extract/Link Data excluded)

**Annotate:** Text (Multiline, Single, style dropdown, height, Find, Spell) · Dimensions (dim style dropdown, Dimension, Linear▾, Aligned, Angular, Radius▾, Ordinate, Arc, Jogged, Quick, Continue▾, Baseline, Space, Break, Edit tools, Reassociate, Inspect, Override) · Centerlines · Leaders (Multileader, style dropdown, Add/Remove Leader, Align, Collect) · Tables (Table, style dropdown) · Markup (Wipeout, Revision Cloud▾) · Annotation Scaling (current scale display; Add/Delete/Sync disabled with tooltip "Annotative creation is view-only in v1")

**Parametric:** Geometric (12 constraints, Show/Hide, Infer) · Dimensional (Linear▾, Aligned, Radius, Diameter, Angular, Show/Hide, Convert) · Manage (Delete Constraints, Parameters Manager, Settings)

**View:** Navigate (Zoom▾, Pan, Previous, Extents, Window, Named Views) · Viewport Tools · Palettes (Properties, Layers, Blocks/Library, References, Constraints, Compare, Health, Command History) · Interface (File tabs, Layout tabs, Status bar, Theme) · Compare (Compare drawings)

**Output:** Plot (Plot, Preview, Page Setup, Plot Styles, Plotter config = n/a) · Export (PDF, SVG, PNG, DXF) · Publish

**Layout:** Layout (New, Page Setup, Delete, Copy) · Layout Viewports (Rectangular, Polygonal, Object, Clip, Lock, Scale list) · (Create View / Modify View / Update / Styles & Standards panels **omitted**; DEC-001)

**Tools:** Drawing Utilities (Units, Audit/Health, Purge, Recover) · Drafting Settings · Options · Alias editor · Keyboard · Clear local data · About

**Contextual tabs** appear while active: Hatch Creation, Text Editor, Table Cell, Block Editor, Xref/Image/PDF Underlay, Array Creation, Compare.

## 3. Responsive ribbon rules (DEC-017)

Breakpoints (viewport width): **≥1920 "full"**, **1600–1919 "wide"**, **1366–1599 "laptop"**, **1280–1365 "compact"**. Minimum supported 1280×720.

- **Full:** three-row labelled ribbon, all panels expanded, large icons with labels, dropdown groups expanded where AutoCAD expands them. This is the professional-drafter mode.
- **Wide:** two-row ribbon; labels on primary items; secondary items icon-only with tooltips.
- **Laptop / Compact:** one-row icon ribbon. **Hard rule: on Home, every item in Draw, Modify and Annotation panels stays visible as an individual icon (dropdown groups keep their split-button) — no overflow menu for those three panels.** Other panels compress in this order: Clipboard → Utilities → Groups → Properties (dropdowns become one combined popover) → Block (collapses to Insert + overflow) → Layers (dropdown + Layer Properties + overflow). If space is still short at 1280, the ribbon scrolls horizontally *only for the non-protected panels*.
- Each item carries explicit size rules in `ribbon.config.ts`: `{ full: 'large-label', wide: 'small-label', laptop: 'icon' }` and a `protected: true` flag for Home Draw/Modify/Annotation.
- Ribbon may be collapsed to tabs-only (double-click a tab) like AutoCAD; a collapsed ribbon pops a panel on click.
- A Playwright test asserts T9 at 1280, 1366, 1600, 1920 and 2560.

## 4. Palettes

- Dockable stack with tabs; drag to reorder; float; auto-hide; width persisted. Below 1366 px palettes open as a right slide-over that overlays the canvas and closes on Esc.
- **Properties:** AutoCAD grouping (General, 3D Visualization with Material only, Geometry, Misc, per-type sections); multi-select shows `*VARIES*`; inline edit with units formatting; Quick Properties for the objects picked (toggle in status bar). Docked from the palette rail, Ctrl+1 or PROPERTIES; the object list ("All (n)", "Line (n)") narrows it to one type; a choice applies when picked, a typed value on Enter or blur (Esc restores); each edit is one undo step (M2-21, #247; Quick Properties is M2-35). With nothing selected the object list reads "No selection" and General shows the drawing's current settings (CECOLOR, CLAYER, CELTYPE, CELTSCALE, CELWEIGHT, CETRANSPARENCY), which a change sets and the objects commands draw take (M2-35 part 1). A text's Style and Justify are choices (a new justification keeps the insertion point), a block reference's Scale X/Y/Z are typed with its attributes following, and a polyline has Global width (M2-35 part 2). A hatch's Pattern name is typed with the pattern library's names offered (SOLID, the bundled patterns and the user's .pat files; AutoCAD's `...` opens its Hatch Pattern Palette), and its Angle, Scale (Spacing and Double for a user-defined hatch) and Island detection style are edited, the pattern laid out again about its origin (M2-35 part 3). A gradient fill has Gradient name, Color 1 and Color 2 (Select Color without colour books; a one-colour gradient has Gradient tint instead of Color 2), Gradient angle and Centered instead of the pattern rows, a pattern has Origin X and Y, and Associative No lets a hatch go of its boundary (M2-35 part 13). Color's last choice, "Select Color...", opens the Select Color dialog (M2-35 part 4): Index Color (the ACI palette, standard colours and greys, ByLayer, ByBlock; the swatch under the pointer reads its index and RGB), True Color (HSL or RGB, number fields and sliders) and Color Books (the books the drawing uses: Triya ships none), with a Color field that takes a name, 1–255, `r,g,b` or `BOOK$COLOR`; for the current colour only Index Color is offered. General also lists Plot style (ByColor, read only, in a colour-dependent drawing; ByLayer and the drawing's plot style names in a named one), Hyperlink (the URL of the object's PE_URL link, its description kept; empty takes it off) and Thickness (on objects with DXF 39), and 3D Visualization the Material (ByLayer and the drawing's materials) (M2-35 part 6). One polyline shows its vertices one at a time (M2-35 part 8): Vertex is a spinner (1 to the vertex count; the arrows, the arrow keys or a typed number), then that vertex's X and Y and the Start and End segment width of the segment leaving it, all editable; the vertex shown is marked on the canvas with an × while one of its rows has the focus. Several polylines show no vertex rows. Misc adds Linetype generation (Enabled/Disabled, PLINEGEN). One MTEXT's Contents has AutoCAD's `...` button, which opens the In-Place Text Editor on it (M2-35 part 9); the MTEXT stays selected and the palette shows the contents written, the edit one undo step. Several MTEXTs show their contents without the button. A dimension's Text group shows Measurement (read only, a length or an angle), and an angular dimension's Primary Units are Angle format, Suppress leading/trailing zeros and Precision, without Alternate Units; linear and angular dimensions together show the rows both have (M2-35 part 10). A multileader whose content is text has a Text group: Contents (read only; one multileader's has the `...` button, which opens the In-Place Text Editor on it), Text style, Justify (Left, Center, Right) and Text height; the text stays on its landing, the side of its box facing the landing kept where it was (M2-35 part 11). Every multileader has a Leaders group before it: Leader type, Leader color (Select Color without colour books), Leader linetype, Leader lineweight, Arrowhead, Arrowhead size, Horz landing and Landing distance; a landing distance keeps the text and the landing's end where they were (M2-35 part 12). The Text group goes on with Text rotation (about the insertion point), Line space factor (0.25 to 4), Line space distance (the factor times 5/3 of the text height), Line space style (At least, Exactly), Background mask (on in the drawing window colour with a 1.5 border) and Text frame; an annotative multileader refuses all but the frame (M2-35 part 14). A multileader holding a block has a Block group in Text's place: Source block (the drawing's named blocks; the new block's attributes take their definitions' values), Block color (Select Color's Index and True Color tabs), Block scale (its own, over the overall scale) and Block rotation, the side of the block facing the landing kept; an annotative multileader refuses them (M2-35 part 15). Quick Properties (M2-35 part 16; AutoCAD's Quick Properties palette, which shows for a selection, not on hover: hovering is its rollover tooltips) is off at first (QPMODE −1, kept per user with QPLOCATION); the status bar's QP button, Ctrl+Shift+P or QPMODE turns it on. Objects picked at `Command:` then show a small palette above and to the right of the cursor, 50 px away (QPLOCATION 0), or top left of the drawing area until its title bar drags it elsewhere (QPLOCATION 1), kept inside the drawing area: the object list, then Color, Layer and Linetype and a few rows of the type shown (Triya's own lists, `QUICK_PROPERTIES`: AutoCAD's live in its CUI file), collapsed to three rows until the pointer or the focus is in it. Edits are the Properties palette's. QPMODE 2 shows it only where a selected type has rows of its own. It does not show while a command runs or while the Properties palette is open, and its × hides it until the selection changes. In surveyor's units (AUNITS 4) angle rows show bearings (`N 45d E`, `W`) and take one typed, with or without spaces (M2-35 part 18). QUICKPROPERTIES shows Quick Properties for the objects selected, or those it asks for at "Select objects", whatever QPMODE says, until the selection changes. Rollover tooltips (ROLLOVERTIPS, on at first, kept per user; Settings' "Show rollover tooltips"): at `Command:`, the cursor resting 400 ms on an object shows a tooltip below and to its right naming the object's type, with its Color, Layer and Linetype (AutoCAD's CUI General entry; Triya ships no CUI, so every type shows those three); moving off the object, a press, the wheel or a command starting takes it away, and none shows while a command runs (M2-35 part 21). While a command's "Select objects" prompt runs the palette shows what it has selected so far, and an edit changes those objects without ending the command, in the command's undo step (M2-35 part 30).
- **Layers:** manager with column chooser, search, filters tree, states menu, VP overrides when a viewport is active, inline edit. *As built (M5-05 part 1):* a New Layer / Delete Layer / Set Current toolbar (Alt+N, Alt+D, Alt+C) over the search box; rows are a multi-selectable list (click, Ctrl+click, Shift+click, ↑/↓, Home/End, Ctrl+A; the selected row is the one focusable row), and On, Freeze, Lock and Plot clicked in a selected row change every selected layer; a double-click on Status sets the layer current, on Name (or F2) and on Description edits them in place (Enter keeps, Esc cancels, leaving the field keeps); Delete deletes the selected layers; a refusal shows in the palette's alert line. *M5-05 part 2:* Color, Linetype, Lineweight and Transparency are buttons in their cells opening Select Color (ByLayer and ByBlock greyed), Select Linetype (Loaded linetypes with Linetype, Appearance and Description; Load... greyed until M5-08), Lineweight (the list, Original and New) and Layer Transparency ("Transparency value (0-90)", typed or picked in tens); OK sets the value on the row clicked, or on every selected layer when the row is one of them, as one LAYER undo step; Esc cancels and the row keeps the focus. *M5-05 part 3:* each column header is a button sorting by its column (▲/▼ and `aria-sort`; a second click reverses); a right-click on the header row, or Shift+F10 / the Menu key on a header, opens the column menu (every column but Name as a check item, Customize..., Restore All Columns to Defaults; a pick closes it); Customize Layer Columns lists the columns with check boxes (Name checked and fixed) in their order, Move Up / Move Down for the focused column, Select All, Clear All, Enter OK, Esc Cancel. The columns and the sort are kept with the preferences. The search hides the rows it leaves out (rows are memoised), so filtering 200 layers stays under 100 ms. *M5-05 part 5:* the columns have widths (a fixed table layout; contents cut with an ellipsis); dragging a header's right edge sizes its column (a double-click there optimizes it); dragging a header sideways moves its column before the header it is dropped on (marked while dragging; a drag never sorts); the column menu, opened on a header, adds Maximize All Columns, Maximize Column, Optimize All Columns, Optimize Column (Optimize fits a column to its header and the rows listed; Maximize also shares the list's free width among the columns maximized) and Freeze Column / Unfreeze Column (the columns up to the one right-clicked stay put while the list scrolls sideways). Widths and the frozen column are kept with the preferences; Restore All Columns to Defaults resets them. The search hides rows with one style rule on each row's lower-case name, so typing renders no row again.
- **Blocks / Library:** current drawing blocks, recent, user library folders, PV standards library with search and preview thumbnails.
- **References:** tree of xrefs/images/PDF underlays with status (loaded/missing/unloaded), paths, actions. M1-21: columns Reference name, Status (Loaded, Not found, Unloaded), Type (Attach, Overlay, Image, PDF underlay), Saved path; Find files…, Choose folder… and Reconnect (kept folders the browser asks about); a status-bar button names how many references are not found and opens the palette. M2-72: a pasted picture's row (its file kept on this device) has Save file…, the save picker for its PNG; a save naming kept pictures shows an offer over the drawing, Save it beside the drawing… (the folder picker opened at the saved DXF, asked once per drawing; later saves write there unasked) or Download it without File System Access, and Not now. Attach/detach/reload/unload/bind are M5-04.
- **Constraints:** list with DOF, conflicts, parameters manager.
- **Compare:** source/target pickers, results list, filters.
- **Health:** report cards with fix buttons.
- **Command History:** F2 equivalent.

## 5. Command line and Dynamic Input

- Two-line docked command window, resizable, with autocomplete (commands, aliases, sysvars), option buttons rendered as clickable chips (`[Undo] [Close]`), recent commands on Up/Down, F2 pops the history palette.
- Dynamic Input: prompt text next to the cursor, numeric fields (distance, angle) with Tab switching and lock, dimension input during drag, pointer input toggle; `DYNMODE` and settings in DRAFTINGSETTINGS.
- Ctrl+K palette: fuzzy search over commands (shows alias and F-key), settings, recent files; Enter runs.
- **As built (M2-02 part 1):** the command window sits under the layout tabs: two history lines over the prompt line, set in a monospace face; the prompt's options are buttons (`[Close/Undo]`, each titled with its shortcut letters) that answer the keyword; completion lists the command an alias names exactly, then the commands whose names begin with what is typed (Tab or a click takes one); Up/Down recall what was entered; F2 toggles the whole history above the command line (Esc in the input closes it). Keys typed outside a text field or dialog go to the command line, and Enter or Space there ends the input (on a button they press it); Esc cancels the running command. While a command waits at a point, distance or angle prompt the canvas shows crosshairs, a left click picks the point under it, and a rubber band follows the cursor from the prompt's base point. A typed number at a rubber-band prompt goes towards the cursor's last point on the canvas (direct distance).
- **As built (M3-10 part 1, `AliasEditor.tsx`, `user-aliases.ts`):** the user alias file (FR-C4): Settings' Command aliases section has Edit aliases…, and Ctrl+K lists Edit Aliases (found by "acad.pgp" and "ALIASEDIT" too). The Edit Aliases dialog holds the file in acad.pgp syntax (`alias,*command`, `;` comments, `*-NAME` for a dash form; a new file is acad.pgp's explanation of the syntax and its "User Defined Command Aliases" heading), says how many aliases it defines and how many take a default alias's place, and lists by line what it cannot use as it is typed: external command lines, lines without a comma, a space in an alias, a command Triya does not have (kept, and answered "Unknown command" as in AutoCAD), a dash form a command lacks, and an alias that is a command's name (AutoCAD looks names up first, "Command Search Order", so it is never used). Default aliases unfolds the default table in the same syntax; Import… reads a .pgp file in place of the text and Export… downloads it as acad.pgp. OK keeps it with the settings (IndexedDB) and every open drawing's command line, its completion and the palette's aliases follow it at once (AutoCAD waits for REINIT); its aliases override the defaults, a later line for one alias winning. Esc or Cancel leaves it unchanged.
- **As built (M3-10 part 2, `keymap.ts`, `shortcuts.ts`, `KeyboardShortcuts.tsx`):** the keyboard map (FR-C5): every shortcut key is looked up in one table of AutoCAD's defaults (F2 history, F3 OSNAP, F7 GRID, F8 ORTHO, F9 SNAP, F10 POLAR, F11 OTRACK, F12 DYN, Ctrl+F/G/L/B/U for OSNAP/GRID/ORTHO/SNAP/POLAR, Ctrl+1 Properties, Ctrl+A, Ctrl+C/X/V, Ctrl+Shift+C/V, Ctrl+Z/Y (Ctrl+Shift+Z too, the Mac's), Ctrl+J and Ctrl+M as Enter, Ctrl+O, Ctrl+S, Ctrl+Shift+S, Ctrl+P, Ctrl+Shift+P, Ctrl+W, Ctrl+Shift+A and Ctrl+H group selection (PICKSTYLE, M3-08); Ctrl+K stays the command palette, AutoCAD's HYPERLINK having no command here); Cmd counts as Ctrl on a Mac. A text field keeps its own keys: Ctrl+A where it holds text, the Clipboard and undo keys anywhere text is typed but an empty command line, Ctrl+B/I/U in a text editor; dialogs and the MTEXT editor keep every key. Settings' Keyboard shortcuts section has Edit shortcut keys…, and Ctrl+K lists Keyboard Shortcuts (found by "CUI" and "Shortcut keys" too). The Keyboard Shortcuts dialog (AutoCAD's CUI Keyboard Shortcuts > Shortcut Keys) lists Name, Keys and Category for every action with keys; Search lists every command too, so any command can take a key. For the action selected its keys show with Remove, and "Press new shortcut key:" takes the next key pressed (Ctrl or Alt with a key, or a function key; keys typed alone are the command line's, so it says so and Assign stays grey) and says what it is "Currently assigned to"; Assign (or Enter) moves it there, Default keys puts the action's defaults back and Reset All every one. OK keeps the map with the settings (IndexedDB) and every key, the palette's keys and the status bar's and Undo/Redo's tooltips follow at once; Esc or Cancel leaves it unchanged. In a browser tab, keys the browser keeps for itself (Ctrl+N, Ctrl+T, Ctrl+W, Ctrl+Tab, Ctrl+Page Up/Down) are marked † with a note that they reach Triya in the installed app. *M3-06 part 5:* the Temporary Override category (`hold` actions, `temp-overrides.ts`): AutoCAD's temporary override keys act while held at a prompt for a point with nothing typed (TEMPOVERRIDES), Shift alone for ORTHO and Shift with a typing key for the others; their keys are Shift alone or Shift with one letter, digit or punctuation key (named by the physical key, so Shift+. is not Shift+>).
- **As built (M3-06 part 8):** DYNPIVIS shows pointer input once typed in, at point prompts, or always (the cursor's X and Y at `Command:` too); grip stretching one object's line end, polyline vertex or circle quadrant shows dimension fields (Resulting Dimension, Length Change, Absolute Angle, Angle Change, Arc Radius), one or two at a time with Tab moving on (DYNDIVIS 0/1) or those DYNDIGRIP names together (2); DYNINFOTIPS adds the tips for Ctrl under the fields; the Drafting Tooltip Appearance dialog sets the tooltip's colour in model space and on layouts, its size (−3 to 6) and transparency (0–90 %), for every drafting tooltip (AutoSnap and tracking too) or Dynamic Input's only. The crosshairs turn with the UCS and SNAPANG. *As built (M3-15):* an arc's end grip shows the chord from its other end (Resulting Dimension, Length Change, Absolute Angle, Angle Change) and the Arc Radius that chord makes with the arc's chord height kept; its middle grip shows the Arc Radius of the arc through both ends. A layout viewport's UCS icon shows the viewport's own UCS while its UCSVP is on, else model space's current UCS; the Properties palette shows a viewport's UCS per viewport (Misc, Yes/No).
- **As built (M3-05 part 7):** at an associative array's count grip (a rectangular array's last column or row, a polar or path array's Count, rows' Row count) dimension input shows one field named for the grip's function (Column count, Row count, Count) holding the count a click at the cursor would give; a number typed in it is the count. Meanwhile the array is drawn remade under the cursor.
- **As built (M2-47 part 3):** keys typed ahead of a prompt are read by the prompt they reach, as AutoCAD buffers type-ahead: `-VIEW` `S` `Two words` typed without waiting saves the view `Two words`, and `-VIEW S Three` typed while a name prompt is still shown starts -VIEW. A space typed before the drawing's engine has answered the last input, and the keys after it, wait for that answer and are then typed into the prompt it shows (a space in a name is text, elsewhere it is Enter). *As built (M2-71):* every key typed before the engine has answered the last input waits, Dynamic Input's like the command line's, and goes into the tooltip's fields when it shows the prompt reached (the cursor over the drawing, nothing typed at the command line), at the command line otherwise: `-VIEW` `S` `Two words` typed fast into the tooltip saves `Two words`, and `LINE` `5,5` `10,0` typed at once draws from 5,5 to 15,5. An Esc typed behind waiting keys cancels after them; a second Esc cancels at once. *As built (M4-20):* keys typed while TEXT's in-place line editor opens go into the editor, not the command line: `TEXT` … Enter `Triya 2D` Enter Enter typed without waiting places the line `Triya 2D` and ends TEXT, each Enter placing the line typed before it; the keys after the Enter that ends TEXT (or after an Esc) wait for `Command:`. *As built (M4-26):* so do keys typed while the MTEXT editor opens after the opposite corner (Enter is a paragraph break there and Tab a tab, as typed into it), or while TEXTEDIT opens its editor on a picked TEXT or MTEXT: the TEXT's value opens selected, so the first key that types replaces it, and Enter keeps the line; after an Esc that cancels, the keys wait for the prompt that follows. Ctrl+Enter is not held, so it ends MTEXT only once the editor shows. A table cell's editor keeps only the keys carried from the cell before it (M4-05 part 7). *As built (M4-31):* the in-place editors number their answers and their Esc as typed input is, so keys typed into an editor after it has answered, while it is still up, are typed ahead of the prompt that answer leads to, at the command line: TEXTEDIT's Enter Enter `LINE` Enter typed without waiting keeps the line, ends TEXTEDIT at `Select an annotation object or [Undo/Mode]:` and starts LINE; so do the keys after TEXT's last Enter and after MTEXT's Ctrl+Enter.
- **As built (M2-02 part 2):** Dynamic Input shows, while a command waits and the cursor is over a drawing, a tooltip right of and below the cursor with the prompt (a ↓ when it has options) and its fields: X and Y at a point prompt (the first point absolute, later ones relative to the last, `#` for absolute; a comma moves to Y), Distance and Angle at a point prompt with a rubber band (`<` or Tab moves to the angle; a distance alone is a direct distance towards the cursor; a comma after a number switches to X and Y relative to the rubber band's base, M2-71, so `#` types an absolute next point; relative points count from that base, which the fields measure from, so COPY's second points all count from its base point), one field at other prompts. Fields left empty show the cursor's values, in the drawing's units since M2-35 part 20 (LUNITS/LUPREC lengths such as `2'-6 1/4"`, AUNITS/AUPREC angles such as `45d0'` or `N 45d E`, as the command line writes them; an angle as it would be typed under ANGBASE and ANGDIR). Tab locks the field typed in (a padlock) and moves on, Backspace unlocks an emptied one; anything that is not a number (an option, `@100<45`, FROM, `'Z`) is sent as typed. ↓/↑ open and move through the options, Enter takes one. Keys typed outside a text field go to the tooltip rather than the command line then (also from the command line's field while it is empty). F12 and the status bar's DYN button toggle it (DYNMODE, on by default). Ctrl+K opens the palette over the drawing: a search box and a list of the commands (with their aliases) and app actions (Command history F2, Dynamic Input F12, Settings), matched fuzzily (whole names and exact aliases first, then prefixes, word starts, scattered letters); ↑/↓ move, Enter runs, Esc or a click outside closes.
