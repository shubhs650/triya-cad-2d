# UI Specification

Design intent: **an AutoCAD drafter finds everything where they expect it; everyone else sees a modern, fast, beautiful tool.** Structure and names come from AutoCAD; execution (icons, spacing, motion, theming, responsiveness) is ours.

## 1. Shell layout

```
┌ Title bar: [OET home] Triya CAD 2D  v1.0 (badge) ─── doc tabs ─── [Report issue] [Settings] ┐
├ Ribbon tabs: Home · Insert · Annotate · Parametric · View · Output · Layout · Tools         │
├ Ribbon panels (responsive, see §3)                                                           │
├─────────────────────────────────────────────────────────┬─────────────────────────────────┤
│                                                         │ Palette stack (dockable)        │
│  Canvas (OffscreenCanvas)                               │  Properties                      │
│  + transient layer                                      │  Layers                          │
│  + Dynamic Input overlay                                │  Blocks / Library                │
│                                                         │  References                      │
│                                                         │  Constraints · Compare · Health  │
├ Model | Layout1 | Layout2 | +  ────────── command line (2 lines, expandable, F2 window) ─────┤
├ Status bar: X,Y,Z · SNAP GRID ORTHO POLAR OSNAP OTRACK DYN LWT TPY QP SC · MODEL/PAPER · 1:10 ▾ · ⚙ ┤
```

- Canvas always wins space. Palettes dock right by default; can float, auto-hide, or dock left/bottom; layout persisted locally.
- Document tabs behave like AutoCAD file tabs (hover preview, close, dirty dot, drag to reorder). Resting the mouse on a tab for 400 ms previews the drawing's Model and layouts (each as last drawn; a space not yet shown is pictured as it would open, by a canvas made only for the picture), resting on a thumbnail shows that drawing and space in the drawing area until the pointer leaves the preview (which brings back what showed before), and clicking one keeps it; Ctrl+Shift+Page Up/Down moves the focused tab. A tab shows a dot after its name while the drawing has unsaved changes (not part of the tab's accessible name); closing it, CLOSE, or leaving the page then asks first, in AutoCAD's message box: "Save changes to <name>?" with Yes (focused), No and Cancel, Esc cancelling. Save and Save As… sit in the title bar (Ctrl+S, Ctrl+Shift+S); a save reports "Saved <name>." in a status notice for 4 s. *As built (M2-57):* that notice and "Opening <name>…" float at the top centre of the drawing area, over the drawing, instead of pushing it down, so the canvas keeps its size (and the view its height) while they come and go; only their Dismiss button takes the pointer.
- Layout tabs sit above the command line; `+` creates a layout; right-click for layout commands.
- *As built (M2-23):* after Open, Save, Save As… and Plot… the title bar's Quick Access part has Undo and Redo, which run U and REDO on the drawing shown (Ctrl+Z, Ctrl+Y; Cmd+Shift+Z on a Mac), each greyed out with nothing to undo or redo and titled with the step it would take back or put back ("Undo LINE (Ctrl+Z)"). Ctrl+Z and Ctrl+Y undo typed text instead wherever text is typed, except an empty command line; in the middle of a command they cancel it first, as a ribbon button does. Each undo or redo shows a toast over the drawing for 2.5 s with what it did and how many steps are left ("Undone: LINE · 3 more to undo", "Undone: 3 steps", "Redone: LINE"). *As built (M2-36):* a ▾ beside Undo and beside Redo opens its drop-down list: the steps by name, newest first for Undo and next first for Redo (at most the newest 100; UNDO n reaches further). Pointing at an entry marks it and every entry above it and the foot says "Undo 3 steps"; picking it undoes or redoes them all as one UNDO n or MREDO n. Arrow keys, Home and End move, Enter picks, Esc or a click elsewhere closes the list.
- *As built (M2-19):* beside the version badge the title bar shows the offline status once the service worker runs (`Saving for offline… n%`, then `Ready offline` in green, `Working offline` with no connection), and an Install button before Settings while the browser would install the app. A new version shows a banner under the title bar, "A new version of Triya CAD 2D is ready. Reload to use it; drawings with unsaved changes ask first.", with Reload and Later; nothing reloads until Reload is pressed.
- *As built (M7-09, PRD §8, DEC-023):* in a browser without Chromium's File System Access, launch queue or web custom clipboard formats (Firefox, Safari), the first visit shows a banner under the title bar, "Triya CAD 2D works in this browser with a few differences. Chrome or Edge has the full feature set. Here:", listing only what that browser lacks (`apps/web/src/browser-support.ts`): Save and Save As download a DXF instead of saving over the opened file; folders dropped for references last until the page closes; copied objects paste in this window only; drawings open with Open or a drop, not a double-click. OK dismisses it for good (the `browserNoticeSeen` preference); it takes no focus and never shows in Chrome or Edge.

## 2. Ribbon content (tabs → panels → items)

Panel names and groupings match AutoCAD so the drafter's spatial memory transfers. Items are the commands in `COMMANDS.md` by tier.

**Home:** Draw (Line, Polyline, Circle▾, Arc▾, Rectangle▾, Ellipse▾, Hatch▾, Spline▾, Xline/Ray, Point▾, Revcloud▾, Wipeout, Region/Boundary) · Modify (Move, Copy, Stretch, Rotate, Mirror, Scale, Trim▾, Extend, Fillet▾, Chamfer, Array▾, Offset, Explode, Erase, Break▾, Join, Lengthen, Align, Overkill) · Annotation (Text▾, Dimension▾, Leader▾, Table, Centerline▾) · Layers (Layer Properties, layer dropdown, tool row) · Block (Insert▾, Create, Edit, Edit Attributes▾) · Properties (Match Properties, colour/linetype/lineweight/transparency dropdowns, Properties palette) · Groups · Utilities (Measure▾, Quick Select, ID, List) · Clipboard

**Insert:** Block (Insert, Edit Attribute, Create Block, Define Attributes, Manage Attributes, Block Editor) · Reference (Attach, Clip, Adjust, Xref palette, Bind) · Library (PV symbols, Weld symbols, GD&T) · Import (PDF underlay) · Data (Field) · Linking (none; Extract/Link Data excluded)

**Annotate:** Text (Multiline, Single, style dropdown, height, Find, Spell) · Dimensions (dim style dropdown, Dimension, Linear▾, Aligned, Angular, Radius▾, Ordinate, Arc, Jogged, Quick, Continue▾, Baseline, Space, Break, Edit tools, Reassociate, Inspect, Override) · Centerlines · Leaders (Multileader, style dropdown, Add/Remove Leader, Align, Collect) · Tables (Table, style dropdown) · Markup (Wipeout, Revision Cloud▾) · Annotation Scaling (current scale display; Add/Delete/Sync disabled with tooltip "Annotative creation is view-only in v1")

**Parametric:** Geometric (12 constraints, Show/Hide, Infer) · Dimensional (Linear▾, Aligned, Radius, Diameter, Angular, Show/Hide, Convert) · Manage (Delete Constraints, Parameters Manager, Settings)

**View:** Navigate (Zoom▾, Pan, Previous, Extents, Window, Named Views) · Viewport Tools · Palettes (Properties, Layers, Blocks/Library, References, Constraints, Compare, Health, Command History) · Interface (File tabs, Layout tabs, Status bar, Theme) · Compare (Compare drawings)

**Output:** Plot (Plot, Preview, Page Setup, Plot Styles, Plotter config = n/a) · Export (PDF, SVG, PNG, DXF) · Publish

**Layout:** Layout (New, Page Setup, Delete, Copy) · Layout Viewports (Rectangular, Polygonal, Object, Clip, Lock, Scale list) · (Create View / Modify View / Update / Styles & Standards panels **omitted**; DEC-001)

**Tools:** Drawing Utilities (Units, Audit/Health, Purge, Recover) · Drafting Settings · Options · Alias editor · Keyboard · Clear local data · About

*As built (M7-02 part 2):* every tab above but Parametric (M9-05) is in `ribbon.config.ts`, with the commands Triya has: Annotate's Annotation Scaling holds Scale List and the greyed-out Add/Delete Scales and Sync Scale Positions (tooltip: "Annotative creation is view-only in v1"); View's Palettes show Properties, Layers, DesignCenter (Blocks/Library until M8-03), External References, Health and Command History in the palette stack, and Interface holds Theme ▾ (Use System Setting, Light, Dark); Tools holds Units, Drawing Health, Purge, Drawing Recovery, Options (OPTIONS, M7-04), Drafting Settings, Linetype, Lineweight, Point Style, Set Variable, Edit Aliases and Keyboard Shortcuts. Every panel of these tabs has a compression rule, the least-used giving up room first. Not yet: View's Compare (M8-06), Interface's File tabs / Layout tabs / Status bar switches, Tools' Clear local data (in Options > System). *As built (M9-07):* Tools ends with a Help panel holding About (the first panel to fold into a ▾ list), which opens the About dialog, as ABOUT does: the version and licence, the PlaneGCS solver module's LGPL-2.1+ and Eigen MPL-2.0 notice with their source links (the LGPL's full text and the spelling dictionary's licence on request), and the third-party software the app ships, read from `ATTRIBUTION.md`. AutoCAD keeps About in its InfoCenter's Help menu, which Triya does not have.

*As built (M9-05 part 1):* the Parametric tab sits between Annotate and View with its Geometric panel: the twelve constraints as icons in AutoCAD's order (Coincident, Collinear, Concentric, Fix, Parallel, Perpendicular, Horizontal, Vertical, Tangent, Smooth, Symmetric, Equal), each running its GC* command (Smooth, GCSMOOTH, since M9-02 part 2). Auto Constrain, Show/Hide and Infer, and the Dimensional and Manage panels come with their commands. *M9-03 parts 3–4:* the Dimensional panel (Linear ▾ with Horizontal and Vertical, Aligned, Radius, Diameter, Angular, Show Dynamic Constraints as a toggle, Convert greyed out). Dynamic constraints are drawn in a blue of their own (light on a dark canvas, deep on a light one), their arrows and text the same size on screen at any zoom. *M9-03 part 5:* the Manage panel's Parameters Manager (PARAMETERS); Delete Constraints and Settings come with their commands. *M9-05 part 3:* the Geometric panel opens with Auto Constrain (large, AUTOCONSTRAIN) and ends with Constraint Settings (AutoCAD's panel launcher, a button here), which opens the Constraint Settings dialog: a modal `<dialog>` with AutoCAD 2024's Geometric, Dimensional and AutoConstrain tabs, opened on the tab shown last (AUTOCONSTRAIN's Settings on AutoConstrain), editing a copy that OK sets; Cancel or Esc closes it only (AUTOCONSTRAIN asks for objects again). The AutoConstrain tab's list is a table (Priority, Constraint Type, Apply): a click or ↑/↓ selects a row, Move Up and Move Down move it; a Distance that is not above 0 or an Angle outside 0–90 shows why and greys OK. Left out: Only display constraint bars for objects in the current plane (no 3D) and Show lock icon for annotational constraints; Infer geometric constraints is greyed until CONSTRAINTINFER. *M9-05 part 7:* Infer geometric constraints is CONSTRAINTINFER; the Geometric panel's Infer Constraints toggle (after Hide All) and the status bar's INFER button (first, as AutoCAD's status bar has it; Ctrl+Shift+I) turn it too.

**Contextual tabs** appear while active: Hatch Creation, Text Editor, Table Cell, Block Editor, Xref/Image/PDF Underlay, Array Creation, Compare.

## 3. Responsive ribbon rules (DEC-017)

Breakpoints (viewport width): **≥1920 "full"**, **1600–1919 "wide"**, **1366–1599 "laptop"**, **1280–1365 "compact"**. Minimum supported 1280×720.

- **Full:** three-row labelled ribbon, all panels expanded, large icons with labels, dropdown groups expanded where AutoCAD expands them. This is the professional-drafter mode.
- **Wide:** two-row ribbon; labels on primary items; secondary items icon-only with tooltips.
- **Laptop / Compact:** one-row icon ribbon. **Hard rule: on Home, every item in Draw, Modify and Annotation panels stays visible as an individual icon (dropdown groups keep their split-button) — no overflow menu for those three panels.** Other panels compress in this order: Clipboard → Utilities → Groups → Properties (dropdowns become one combined popover) → Block (collapses to Insert + overflow) → Layers (dropdown + Layer Properties + overflow). If space is still short at 1280, the ribbon scrolls horizontally *only for the non-protected panels*.
- Each item carries explicit size rules in `ribbon.config.ts`: `{ full: 'large-label', wide: 'small-label', laptop: 'icon' }` and a `protected: true` flag for Home Draw/Modify/Annotation.
- Ribbon may be collapsed to tabs-only (double-click a tab) like AutoCAD; a collapsed ribbon pops a panel on click.
- A Playwright test asserts T9 at 1280, 1366, 1600, 1920 and 2560.
- *As built (M7-01):* `apps/web/src/ribbon/ribbon.config.ts` holds the tabs, panels and items (Home and Insert so far; M7-02 adds the rest) and `ribbon/layout.ts` lays them out. Full is three rows (large buttons span all three), wide two, laptop and compact one row of 24 px icons with each panel's title under it. A compressible panel either keeps the items its rule names plus a ▾ overflow list (Properties, Block, Layers) or becomes one ▾ button listing the whole panel (Clipboard, Utilities, Groups); the ribbon compresses only as far as the panels actually overflow, measured before paint, so a wide window keeps more panels whole. At 1280 and 1366 the protected panels take about 1,130 px and the compressed rest scrolls by itself; the page never does. Split buttons run the entry picked last (AutoCAD's behaviour) and say which in their tooltip ("Circle: 2-Point"); entries that need a keyword type it at the command's first prompt, as AutoCAD's ribbon macros do. A mouse click leaves the focus on the page so Enter and Space reach the command line; tabs move with the arrow keys; lists open on the first entry, move with the arrows and close with Esc back on their button. *As built (M7-02 part 1):* items show Fluent UI System Icons where Fluent has one that says the command and Triya's CAD glyphs (same 20 px grid and 1 px line weight) where it has not, 32 px over a large button's label and 20 px elsewhere; the Quick Access Undo and Redo show Fluent's arrows. Resting the pointer 500 ms on an item, or focusing it from the keyboard, shows AutoCAD's rich tooltip under it: the name (a split button's with the entry it runs, "Circle: 2-Point"), a line on what it does, then Command (with the keywords it types), Alias(es) and Key(s); Esc, a click or the pointer leaving hides it. Hover lifts an icon by a pixel, a press sinks the button, lists and tooltips fade in, all within `--motion` (none under reduced motion). *As built (M7-02 part 3):* Home's Layers and Properties dropdowns (`ribbon/RibbonControls.tsx`) show the selected objects' layer, colour, linetype, lineweight and transparency, `*VARIES*` where they differ, or the current settings with nothing selected; a pick changes the objects or the current setting. The layer list shows each layer's colour and toggles its on, freeze and lock states; the colour list ends with Select Colors..., the linetype list with Other... (Linetype Manager) and the lineweight list with Lineweight Settings.... Full puts the layer dropdown over two rows of layer tools beside Layer Properties and the colour, linetype and lineweight dropdowns in a column beside Match Properties, transparency as an icon dropdown. The layer dropdown keeps its name at every size and in a compressed Layers panel; the other dropdowns are icons with a swatch on the one-row ribbon and, when Properties compresses, entries of its ▾ list showing their values, each opening its list there. *As built (M7-02 part 4):* a contextual tab joins the tab row after Tools, its name in the accent colour, and is brought up as it appears: Hatch Creation while HATCH or GRADIENT runs, Array Creation while ARRAYRECT, ARRAYPOLAR or ARRAYPATH runs, Table Cell while table cells are selected (TABLECELL), Block Editor while the Block Editor is open, and Hatch Editor, Image, PDF Underlay, External Reference or Array while everything selected is of that kind (a command's tab before the Block Editor's, that before a selection's). Its buttons answer the running command's prompt with their keyword, as AutoCAD's do; each tab ends with a Close button (Enter or eXit for a command, Esc for a selection or table cells, BCLOSE for the Block Editor). When it goes, the tab shown before it comes back; the other tabs stay a click away while it shows. *As built (M7-02 part 5):* Annotate's Text, Dimensions, Leaders and Tables panels each have a style dropdown naming the current style; its list holds the drawing's styles of that kind, the current one picked, and ends with Manage Text Styles... (or Dimension, Multileader, Table), which opens the style dialog. Picking one makes it current, transparently, so a command running goes on with it. While MTEXT's in-place editor is open the Text Editor tab shows, over any other contextual tab: its Formatting toggles (Bold and Italic greyed for an SHX font), Stack, Paragraph, Columns, Field and Spell Check are the editor's toolbar's, pressed as the text at the caret is, and act on the editor's selection; a click on the tab keeps the editor open, and Close Text Editor keeps the text, as Ctrl+Enter does.

## 4. Palettes

- Dockable stack with tabs; drag to reorder; float; auto-hide; width persisted. Below 1366 px palettes open as a right slide-over that overlays the canvas and closes on Esc. *As built (M7-03 part 1, `palette-stack.ts`, `PaletteDock.tsx`):* the palettes open together as tabs of one stack (the "Palette stack" region) between the drawing area and the Palettes rail. A rail button, a palette's command (PROPERTIES, ADCENTER, …) or its key (Ctrl+1, Ctrl+2) brings that palette to the front, opening it after the front tab when it is not open; the button of the palette in front, or its key, closes it, and its header's × closes it wherever it is, the tab after it (else before it) coming to the front. Only the front palette is drawn (a palette behind is not open for Quick Properties' rule or the engine). The tabs are a tab list: a click or ←/→, Home/End bring one to the front; dragging a tab sideways, or Ctrl+Shift+Page Up/Down on it, moves it. The button at the end of the tab strip (⇤ "Dock palettes left", ⇥ "Dock palettes right") docks the stack and its rail on the other side. The "Palette width" handle on the stack's edge facing the drawing is dragged, or focused and moved with ←/→ (16 px, Shift 64 px), Home and End (240 to 800 px; at most 45 % of the window docked). The tabs, the front tab, the side and the width are kept with the preferences and come back next session. Below 1366 px the stack slides over the drawing area beside the rail (the drawing area keeps its size; a 140 ms slide, none with reduced motion); Esc there, outside a field or menu, slides it away and focuses the front palette's rail button, the tabs staying open for the rail to bring back. *As built (M7-03 part 2):* the tab strip starts with a grip (⠿ "Move palettes"); dragging it, or the strip's free part, takes the stack off its dock and floats it where it is dropped (over the drawing area, its own width and height, kept inside the window when the window shrinks; the arrow keys on the grip move it 16 px, Shift 64 px). Dropped within 32 px of the drawing area's left, right or bottom edge (a band there shows where), it docks there instead. Docked at the bottom, the stack lies under the drawing area, as wide as it, the rail staying at its side; its "Palette height" handle on its top edge (120 to 600 px; at most half the window) is dragged or moved with ↑/↓ (16 px, Shift 64 px), Home and End. A floating stack has the "Palette width" handle on its right edge and "Palette height" on its bottom edge. The ⋮ "Palette options" button at the strip's end opens AutoCAD's palette menu: Dock Left, Dock Right, Dock Bottom, Float (the place checked), then Auto-hide; ↑/↓, Home/End move, Enter picks, Esc closes it. With Auto-hide on, the stack lies over the drawing area (which keeps its size) collapsed to its tab strip (upright along the edge when docked at a side) and opens when the pointer rests on it (200 ms) or the keyboard focuses it; it closes once the pointer has left (300 ms) and the focus is elsewhere, or on Esc outside a field or menu. Docked at the bottom or floating, the stack takes no width from the drawing area, so below 1366 px it does not slide over. The floating place and size, the bottom height and auto-hide are kept with the rest of the layout. Blocks/Library, Constraints and Compare join the stack with their palettes (M8-03, M9-05, M8-06).
- **Properties:** AutoCAD grouping (General, 3D Visualization with Material only, Geometry, Misc, per-type sections); multi-select shows `*VARIES*`; inline edit with units formatting; Quick Properties for the objects picked (toggle in status bar). Docked from the palette rail, Ctrl+1 or PROPERTIES; the object list ("All (n)", "Line (n)") narrows it to one type; a choice applies when picked, a typed value on Enter or blur (Esc restores); each edit is one undo step (M2-21, #247; Quick Properties is M2-35). With nothing selected the object list reads "No selection" and General shows the drawing's current settings (CECOLOR, CLAYER, CELTYPE, CELTSCALE, CELWEIGHT, CETRANSPARENCY), which a change sets and the objects commands draw take (M2-35 part 1). A text's Style and Justify are choices (a new justification keeps the insertion point), a block reference's Scale X/Y/Z are typed with its attributes following, and a polyline has Global width (M2-35 part 2). A hatch's Pattern name is typed with the pattern library's names offered (SOLID, the bundled patterns and the user's .pat files; AutoCAD's `...` opens its Hatch Pattern Palette), and its Angle, Scale (Spacing and Double for a user-defined hatch) and Island detection style are edited, the pattern laid out again about its origin (M2-35 part 3). A gradient fill has Gradient name, Color 1 and Color 2 (Select Color without colour books; a one-colour gradient has Gradient tint instead of Color 2), Gradient angle and Centered instead of the pattern rows, a pattern has Origin X and Y, and Associative No lets a hatch go of its boundary (M2-35 part 13). Color's last choice, "Select Color...", opens the Select Color dialog (M2-35 part 4): Index Color (the ACI palette, standard colours and greys, ByLayer, ByBlock; the swatch under the pointer reads its index and RGB), True Color (HSL or RGB, number fields and sliders) and Color Books (the books the drawing uses: Triya ships none), with a Color field that takes a name, 1–255, `r,g,b` or `BOOK$COLOR`; for the current colour only Index Color is offered. General also lists Plot style (ByColor, read only, in a colour-dependent drawing; ByLayer and the drawing's plot style names in a named one), Hyperlink (the URL of the object's PE_URL link, its description kept; empty takes it off) and Thickness (on objects with DXF 39), and 3D Visualization the Material (ByLayer and the drawing's materials) (M2-35 part 6). One polyline shows its vertices one at a time (M2-35 part 8): Vertex is a spinner (1 to the vertex count; the arrows, the arrow keys or a typed number), then that vertex's X and Y and the Start and End segment width of the segment leaving it, all editable; the vertex shown is marked on the canvas with an × while one of its rows has the focus. Several polylines show no vertex rows. Misc adds Linetype generation (Enabled/Disabled, PLINEGEN). One MTEXT's Contents has AutoCAD's `...` button, which opens the In-Place Text Editor on it (M2-35 part 9); the MTEXT stays selected and the palette shows the contents written, the edit one undo step. Several MTEXTs show their contents without the button. A dimension's Text group shows Measurement (read only, a length or an angle), and an angular dimension's Primary Units are Angle format, Suppress leading/trailing zeros and Precision, without Alternate Units; linear and angular dimensions together show the rows both have (M2-35 part 10). A multileader whose content is text has a Text group: Contents (read only; one multileader's has the `...` button, which opens the In-Place Text Editor on it), Text style, Justify (Left, Center, Right) and Text height; the text stays on its landing, the side of its box facing the landing kept where it was (M2-35 part 11). Every multileader has a Leaders group before it: Leader type, Leader color (Select Color without colour books), Leader linetype, Leader lineweight, Arrowhead, Arrowhead size, Horz landing and Landing distance; a landing distance keeps the text and the landing's end where they were (M2-35 part 12). The Text group goes on with Text rotation (about the insertion point), Line space factor (0.25 to 4), Line space distance (the factor times 5/3 of the text height), Line space style (At least, Exactly), Background mask (on in the drawing window colour with a 1.5 border) and Text frame; an annotative multileader refuses all but the frame (M2-35 part 14). A multileader holding a block has a Block group in Text's place: Source block (the drawing's named blocks; the new block's attributes take their definitions' values), Block color (Select Color's Index and True Color tabs), Block scale (its own, over the overall scale) and Block rotation, the side of the block facing the landing kept; an annotative multileader refuses them (M2-35 part 15). Quick Properties (M2-35 part 16; AutoCAD's Quick Properties palette, which shows for a selection, not on hover: hovering is its rollover tooltips) is off at first (QPMODE −1, kept per user with QPLOCATION); the status bar's QP button, Ctrl+Shift+P or QPMODE turns it on. Objects picked at `Command:` then show a small palette above and to the right of the cursor, 50 px away (QPLOCATION 0), or top left of the drawing area until its title bar drags it elsewhere (QPLOCATION 1), kept inside the drawing area: the object list, then Color, Layer and Linetype and a few rows of the type shown (Triya's own lists, `QUICK_PROPERTIES`: AutoCAD's live in its CUI file), collapsed to three rows until the pointer or the focus is in it. Edits are the Properties palette's. QPMODE 2 shows it only where a selected type has rows of its own. It does not show while a command runs or while the Properties palette is open, and its × hides it until the selection changes. In surveyor's units (AUNITS 4) angle rows show bearings (`N 45d E`, `W`) and take one typed, with or without spaces (M2-35 part 18). QUICKPROPERTIES shows Quick Properties for the objects selected, or those it asks for at "Select objects", whatever QPMODE says, until the selection changes. Rollover tooltips (ROLLOVERTIPS, on at first, kept per user; Settings' "Show rollover tooltips"): at `Command:`, the cursor resting 400 ms on an object shows a tooltip below and to its right naming the object's type, with its Color, Layer and Linetype (AutoCAD's CUI General entry; Triya ships no CUI, so every type shows those three); moving off the object, a press, the wheel or a command starting takes it away, and none shows while a command runs (M2-35 part 21). While a command's "Select objects" prompt runs the palette shows what it has selected so far, and an edit changes those objects without ending the command, in the command's undo step (M2-35 part 30).
- **Layers:** manager with column chooser, search, filters tree, states menu, VP overrides when a viewport is active, inline edit. *As built (M5-05 part 1):* a New Layer / Delete Layer / Set Current toolbar (Alt+N, Alt+D, Alt+C) over the search box; rows are a multi-selectable list (click, Ctrl+click, Shift+click, ↑/↓, Home/End, Ctrl+A; the selected row is the one focusable row), and On, Freeze, Lock and Plot clicked in a selected row change every selected layer; a double-click on Status sets the layer current, on Name (or F2) and on Description edits them in place (Enter keeps, Esc cancels, leaving the field keeps); Delete deletes the selected layers; a refusal shows in the palette's alert line. *M5-05 part 2:* Color, Linetype, Lineweight and Transparency are buttons in their cells opening Select Color (ByLayer and ByBlock greyed), Select Linetype (Loaded linetypes with Linetype, Appearance and Description; Load... opens Load or Reload Linetypes and loads the linetypes picked, the first chosen, since M5-08 part 1), Lineweight (the list, Original and New) and Layer Transparency ("Transparency value (0-90)", typed or picked in tens); OK sets the value on the row clicked, or on every selected layer when the row is one of them, as one LAYER undo step; Esc cancels and the row keeps the focus. *M5-05 part 3:* each column header is a button sorting by its column (▲/▼ and `aria-sort`; a second click reverses); a right-click on the header row, or Shift+F10 / the Menu key on a header, opens the column menu (every column but Name as a check item, Customize..., Restore All Columns to Defaults; a pick closes it); Customize Layer Columns lists the columns with check boxes (Name checked and fixed) in their order, Move Up / Move Down for the focused column, Select All, Clear All, Enter OK, Esc Cancel. The columns and the sort are kept with the preferences. ## 12. Accessibility (M7-10)

The baseline every screen keeps, checked by `tests/e2e/ui/accessibility.spec.ts`:

- **No critical axe rule broken**, nor the serious ARIA naming and focus rules: the start screen, the drawing window, every ribbon tab, every palette, the split-button menus, the shortcut menu, the Ctrl+K palette and every dialog. The check is Triya's own (`tests/e2e/app/a11y.ts`, DEC-079): axe-core's rules re-implemented, as axe-core's MPL-2.0 licence is not on the allowed list, with Chromium's own accessible names.
- **Every dialog works from the keyboard alone**: opened from the command line it has the focus; Tab stays inside it and reaches every enabled control, or the one stop of a tab list, list box, grid or tree, whose items the arrow keys move along; nothing in it answers only to the pointer; Esc closes it and the focus goes back to the element that had it (the command line, or the button that opened it), or to the command line when that element is gone (`apps/web/src/modal-dialog.ts`).
- **Focus order follows the screen**: a "Skip to command line" link (shown while focused), the title bar with the drawing tabs, the ribbon, the drawing area's navigation bar, the palette rail, the layout tabs, the command line, the status bar. No positive `tabindex`.
- **Drawing tabs** are one Tab stop (the drawing shown): ←/→ (wrapping), Home and End move the focus, Enter or Space shows the drawing focused, Delete closes it (the tab's `aria-keyshortcuts`); the × is for the pointer only, since a tab list holds tabs alone. Enter or Space on any control the arrow keys focused presses it; the command line takes the key only on the page or the canvas.
- The Layers palette's list and Edit Layer State's list are grids (`role="grid"`, multi-selectable rows), not tables.
