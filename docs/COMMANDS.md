# Command and Alias Reference (normative)

This is the command surface a drafter expects. Aliases are the AutoCAD `acad.pgp` defaults. **Tier 1** = required for the markup workflow (M2). **Tier 2** = required for v1 complete. **Tier 3** = Should. Status: ` ` open · `~` in progress · `x` done (PR). Threads update the Status column in the same PR that lands the command. A command is "done" only with its options, prompts, Dynamic Input behaviour, and tests.

Transparent commands (usable mid-command with `'`) are marked ᵀ. Dash variants (`-NAME`) are required where noted.

The Aliases column is the engine's alias table (`ALIASES` in `packages/engine/src/commands/aliases.ts`, M2-01); `tests/docs/commands-aliases.test.ts` fails if the two differ, so change both together. Keyboard shortcuts (Ctrl+…, F-keys) in that column belong to the UI. The user alias file (M3-10, Settings' Edit Aliases, acad.pgp syntax) overrides these defaults per user: `CommandRegistry.setUserAliases`, `parseAliasFile`. The keys are the keyboard map's defaults (`KEY_ACTIONS` in `apps/web/src/keymap.ts`, M3-10 part 2), which the Keyboard Shortcuts dialog (Settings, Ctrl+K) changes per user; any command can take a key there.
