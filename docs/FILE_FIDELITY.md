# File Fidelity Matrix

One row per DXF/DWG entity, object or table type. A type is **done** only when all five columns are ticked and a corpus file exercises it. Threads update rows in the PR that lands the work. "P" in a column means handled purely by passthrough (preserved, not interpreted) — that is a valid final state for the types marked *(passthrough-only)*.

Since M1-05 every save goes through `exportDocument`: it starts from the retained original and writes back only what differs from the original's own mapping, so a type Triya does not edit is written back untouched (its Write cell stays empty until its writer exists, roadmap M1-75), and the round-trip suite gates zero differences on every readable corpus file.

**Scope since DEC-047 (2026-11-08):** Triya saves DXF only, as AC1032. DWG cells and pre-AC1032 rows record what was built before that decision; they get no new work before launch. The **Render** column means drawn following AutoCAD's documented rules and checked against Triya's own golden images, not AutoCAD plots. Anything marked as waiting on an owner sample is post-launch.

Columns: **Read** (mapped into Triya model) · **Render** (drawn like AutoCAD) · **Edit** (modifiable by Triya commands) · **Write** (rebuilt on export without loss) · **Test** (corpus file + round-trip + fidelity reference).

**AC1032 DXF save validity (M1-105, DEC-047 item 7):** every readable public corpus file, whatever its version or format, is saved as AC1032 DXF unedited and with the export suite's edit, and each save must load with ezdxf `recover` and pass its `audit` with nothing to report (`scripts/dxf-audit/audit.py`, in the required CI job). The only findings allowed are the ones ezdxf reports on the source file too, listed per file with the reason in `scripts/dxf-audit/exceptions.json`: an invalid lineweight in `valid_lineweights.dxf` and the proxy objects in the R13/R14 binary DXFs' dictionaries, both kept as read. One ezdxf limitation is allowed where the script verifies it in the save: ezdxf's audit drops an extension dictionary attached to a DICTIONARY (AutoCAD's `ACAD_XREC_ROUNDTRIP` data in `sample_AC1014.dwg`) and reports its XRECORDs, which it also does on a file it wrote itself.

Writing to a version older than the source drops entities that didn't exist in that version; Triya warns with the list before saving and never drops silently.
