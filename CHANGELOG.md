# Changelog

All notable changes are recorded here by the thread that lands them (one line per merged task, newest first).

## Unreleased
- M1-04 part 2 (#19): `mapEntities` maps TEXT, MTEXT, ATTDEF and INSERT/MINSERT, with each INSERT's ATTRIBs folded in (own handle and properties, multiline MTEXT embedded); −Z text and inserts convert exactly (DEC-039 extended). Corpus oracle checks text frames and insert placements by probe points; new acad-ts gaps (attribute mirror flags, caret codes) added to M1-32.
- M1-04 part 1 (#17): `mapEntities` in `@triya/io` maps LINE, XLINE, RAY, CIRCLE, ARC, ELLIPSE, POINT, LWPOLYLINE, POLYLINE (2D/3D) with VERTEX, SPLINE, SOLID/TRACE and 3DFACE of every block record into plan-view engine entities (DEC-039), with common properties; other types are listed as unmapped. Corpus oracle test compares every such entity of the public ASCII DXFs.
- M1-27 (#15): handle-coverage gate in the round-trip suite: every handle a corpus file declares (DWG handle map typed per record, ASCII and binary DXF `5`/`105`) must be in the reopened document; known losses ratcheted by handle in `corpus/handle-coverage-baseline.json` (4,902 of 46,712: 919 never loaded, 3,983 dropped on save). No allow-list (DEC-038). Residue split into M1-31 (writer) and new M1-33 (reader).
- M1-03 part 2 (#16): dimension styles with every DIMVAR by name (colours as ACI, references as handles), multileader styles and table styles (cell styles and borders) from their named-object dictionaries; corpus oracle extended to DIMSTYLE groups and the style objects. M1-03 complete; new acad-ts gaps added to M1-32.
- M1-03 part 1 (#14): `AcadToTriya` for symbol tables and the header (`mapTables`, `mapHeader` in `@triya/io`): layers (transparency from xdata), linetypes, text styles, app ids, views, UCSs, vports and block records with xdata, reactors and extension dictionaries; every header variable acad-ts knows by DXF name. Corpus oracle test against an independent DXF reader; acad-ts read gaps it found are M1-32.
- M1-30 (#9): acad-ts keeps objects it cannot map as raw data (DXF group codes, DWG object records) and writes them back under their handles; also links SUN and 3DSOLID history, keeps same-name DWG classes and class numbers, reads XRECORD-owned objects, and fixes LAYOUT plot flags (DXF) and `$CELWEIGHT` (DWG) (patches 0014–0020). All 1,329 unknown objects in the public corpus survive a save; round trip 26,728 → 26,527 differences. Remaining drops moved to M1-31.
- M1-02 part 3 (#13): `engine/geom` closest point (exact for lines and arcs, branch and bound for ellipses and splines), tangent directions and TAN points from a point, offsets of every curve (left of travel for positive distances; polylines joined as OFFSETGAPTYPE 0; ellipse/spline offsets sampled into polylines) and `sideOf`. M1-02 complete.
- M1-02 part 2 (#12): `engine/geom` intersections of every curve pair (`intersect`): closed forms for line/circle/ellipse pairs, flatten-seed-Newton with subdivision for splines and the rest, isolated points only (DEC-037); NURBS second derivatives.
- M1-02 part 1 (#11): geometry kernel `engine/geom`: vectors, angles, extents-derived `Tolerance` (DEC-036), curve shapes shared with the model, parametric evaluation of every curve type, NURBS (rational, unclamped) evaluation, flattening within a deviation, exact bounds (polished spline extremes), affine transforms of curves; ≥ 95 % coverage gate on `engine/geom` in `pnpm test`.
- M1-01 (#10): document model in `@triya/engine` (`engine/src/model`): entity/table/object/header types, frozen-value update helpers, `HandleAllocator` above `$HANDSEED` (monotonic, raises stale seeds), permanent `EntityIdMap`, atomic `DocumentModel.apply`, invertible `ChangeSet` with block positions, and `ChangeSetBuilder` for commands (DEC-035). fast-check added for property-based tests.
- M0-GO: owner accepted the M0-06 CONDITIONAL GO (#7); M1 read-only work released, Save stays blocked on M1-27 to M1-30 and the deferred M0-07 AUDIT.
- M0-06 (#6): acad-ts spike, recommendation CONDITIONAL GO (`docs/reports/M0-acad-ts-spike.md`). acad-ts patches 0002–0013 and a fidelity writer profile take the public round trip from 35,447 to 26,728 differences and 0 to 11 clean files; `pnpm spike:read` / `pnpm spike:roundtrip` report failure taxonomy and handle coverage (4,379 of 36,911 declared objects never loaded). Follow-ups M1-27 to M1-30.
- M0-05 (#5): round-trip harness in `@triya/testkit` (`roundTrip`, `structuralDiff`, per-file report, regression ratchet in `corpus/roundtrip-baseline.json`), `writeCadDocument` in `@triya/io`, `pnpm corpus:roundtrip`. Baseline: 118 of 119 public files round-trip with differences, 1 read error; snapshot in `docs/reports/M0-roundtrip-baseline.md`. DEC-034 allows `$TDUUPDATE`.
- M0-03 (#3): acad-ts vendored at upstream 315f3d8 as a filtered snapshot (DEC-033) with patch 0001 (ESM-safe `createExtendedDictionary`); `@triya/io` reads DWG/DXF in Node and in a module Web Worker under Vite (`pnpm test:io`).
- M0-04 (#2): public corpus skeleton: 119 MIT-licensed ezdxf and ACadSharp drawings (R12–R2018, DWG and ASCII/binary DXF), `corpus.json` manifest + JSON schema, `pnpm corpus:list` / `pnpm corpus:validate` in `@triya/testkit`.
- M0-01 (#1): pnpm/turbo monorepo scaffold with strict TypeScript, ESLint module-boundary and no-DOM rules (tested edge by edge), Prettier, Vitest, Playwright suites, Husky pre-commit, and every pnpm script CI calls.
- Kickoff kit: PRD, architecture, roadmap, decisions, testing, UI spec, command reference, fidelity matrix, M0 spike plan, CLAUDE.md, CI scaffold.
