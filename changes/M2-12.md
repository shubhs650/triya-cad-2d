- M2-12 (#236): attribute editing. A double click on a block reference with attributes opens the Enhanced Attribute Editor (EATTEDIT: values, text options and properties, Apply, Select block; a multiline value edits in the MTEXT editor), ATTEDIT opens Edit Attributes, -ATTEDIT edits one at a time or replaces a string globally with wildcards, and TEXTEDIT or a double click on an attribute definition opens Edit Attribute Definition. Edited attributes save to DXF under their own handles.
