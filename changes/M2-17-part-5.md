- M2-17 part 5 (#265): -PLOT plots at the command line without the dialog, for scripts. It asks AutoCAD's -PLOT prompts (the short form: layout, page setup, output device, file; or the detailed configuration: paper, units, orientation, upside down, plot area and window, scale or Fit, offset or Center, plot styles and table, lineweights, and a layout's own options), each defaulting to what the Plot dialog opens on for that space; `?` lists the layouts, devices, papers or tables. "Save changes to page setup" saves the answers into the space's page setup as one undo step, as Apply to Layout does.
