- M7-08 part 1 (#639): the error report. When something goes wrong (an uncaught error, or a command that fails), a panel at the bottom right shows the report Triya would send, in full, with Send Report and Don't Send; nothing is sent until Send Report. The report holds the error, its code locations, your browser and the app version, and counts of what the drawing holds, never its text, names, file names or paths (a test checks a drawing full of marker strings). Options > System can turn the offer off. Reports go to a Cloudflare Worker that files them as GitHub issues (deployment is M10-08).
