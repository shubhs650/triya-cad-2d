- M2-07 part 2 (#232): edit existing text in place. TEXTEDIT (DDEDIT, ED) or a double click on a TEXT or MTEXT opens its editor holding what it says; the MTEXT editor keeps the formatting it has no buttons for (paragraph indents, alignment and bullets, width, tracking, obliquing, column breaks), so editing one word of a drawing's note changes nothing else. The MTEXT editor also gets a Font list and AutoStack (typing `1/2 ` stacks the fraction), TEXT starts its next line wherever you click, and a text can be picked anywhere inside its letters' box.
