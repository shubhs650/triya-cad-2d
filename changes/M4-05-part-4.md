- M4-05 part 4 (#441): table cells are selected by dragging across them, and the cell menu fills them (Background Fill), aligns them (Alignment), gives them borders (Borders: all, outside, inside or one side, a colour and lineweight) and sets their text height (rows growing to fit). A table's grips size it (width, height or both, in proportion) and a grip atop each column line moves it, the table keeping its width. SCALE now scales a table's text and margins with it, so the table draws the same when edited later. Each saves and reads back.
