- M5-02 part 4 (#532): BEDIT inside the Block Editor, and <Current Drawing>. The Block Editor bar's Edit Block (or BEDIT / -BEDIT typed there) opens another block in the editor's place, asking first whether to save or discard edits not saved. The Edit Block Definition dialog lists <Current Drawing> above the blocks: the drawing itself opens in the editor, where BASE sets the drawing's base point and closing with Discard takes back what was drawn.
