- M1-36 (#119): table cells now carry their formatting overrides when opened: alignment, text style and height, content colour, background or no fill, edge colours, lineweights and hidden edges, and margins. DXF and DWG files of the same drawing give the same result. acad-ts patch 0109 fixes four table read bugs: R2010+ right-edge overrides were put on the inside line, R2004 edge visibility read inverted, R2010+ cell-style override flags were overwritten, and a DXF cell's text style was dropped.
