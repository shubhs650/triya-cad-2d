- M5-09 part 1 (#530): -PURGE (alias PU; PURGE runs the same prompts until its dialog) removes what nothing uses: blocks with the objects in them, dimension, text, multileader, table and MLINE styles, empty groups, layers (out of the viewports and layer states that name them), linetypes, materials, plot styles, visual styles and registered applications, by name or wildcard, each confirmed or not; All goes through every kind. It never takes what AutoCAD keeps (layer 0, Defpoints, Standard styles, ACAD, current items, xref records) nor anything the file still refers to, so a purged drawing always saves. Zero-length geometry and empty text objects are deleted from model space and layouts, not from blocks or locked layers. One undo step per run.
