- M4-09 part 2 (#456): FIND opens the Find and Replace dialog. It finds and replaces text in text and multiline text, block attribute values, dimensions and multileaders, table cells and hyperlinks, in the current space, the whole drawing or the selected objects, with match case, whole words, wildcards, search blocks, ignore hidden items, diacritics and half/full width options; it lists the results, zooms to each match and keeps the text's formatting when replacing.
