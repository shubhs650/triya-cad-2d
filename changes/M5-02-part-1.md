- M5-02 part 1 (#523): the Block Editor. BEDIT opens the Edit Block Definition dialog (the drawing's blocks with a preview and description; a selected or double-clicked block reference opens its block) and -BEDIT asks for the name at the command line; the block shows in the Block Editor, whose bar replaces the layout tabs, and every command draws and edits in its definition, so each reference follows at once. BSAVE (Save Block) keeps the edits, BCLOSE (Close Block Editor) asks whether to save or discard edits not saved, and Discard takes them back in one undo step. BASE in the editor moves the block's base point, INSERT refuses the block being edited, and BLOCKEDITOR tells whether the editor is open.
