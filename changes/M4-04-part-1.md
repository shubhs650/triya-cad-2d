- M4-04 part 1 (#439): STYLE opens AutoCAD's Text Style dialog: choose a style's font (TrueType Bold/Italic, SHX with a big font), height and effects (upside down, backwards, vertical, width factor, oblique angle), Apply, make new styles, set one current, rename and delete unused ones; -STYLE does the same at the command line. Text redraws in the new font at once and every setting survives a DXF save.
