- M10-01 part 1 (#694): saving a large drawing is up to seven times faster and opening one about twice as fast. A DXF save no longer writes the file again each time its buffer grows (bench-100k: 32 s → 4.5 s), and reading a DXF no longer makes a text decoder for each line (acad-ts patch 0191; bench-100k opens to its first frame in about 7 s instead of 12). The perf suite now times open, save and memory in the app itself (`tests/e2e/perf/bench.spec.ts`, DEC-096).
