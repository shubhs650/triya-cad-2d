- M1-110 (#218): vertical text. TEXT in a vertical text style, and MTEXT drawn top to bottom (or "by style" in a vertical style), now stack their characters down a column when the font is an SHX font that supports vertical text, as AutoCAD draws them; an MTEXT's lines become columns set right to left. In any other font (the bundled Hershey fonts, TrueType, horizontal-only SHX) they draw horizontally as before, so no corpus drawing changes.
