- M5-05 part 1 (#500): the Layers palette becomes the Layer Properties Manager's list: rows are selected as AutoCAD's are (click, Ctrl+click, Shift+click, arrow keys, Ctrl+A) and a toggle clicked in a selected row changes every selected layer; New Layer (Alt+N) adds LayerN with the selected layer's properties and names it in place, Delete Layer (Alt+D, Delete) removes the layers AutoCAD lets go (not layer 0, Defpoints, the current layer, layers with objects or xref-dependent layers) and takes them out of the viewports that freeze them, Set Current (Alt+C, or a double-click on Status) makes a layer current, a double-click or F2 renames a layer ($CLAYER follows) and a double-click on Description edits it, and Plot is a toggle. Each is one LAYER undo step.
