- M5-02 part 2 (#526): new blocks from the Block Editor and ATTSYNC. A name no block has, typed in Edit Block Definition or at -BEDIT, makes an empty block and opens it in the Block Editor (closing without saving takes it away again); the Block Definition dialog's "Open in block editor" shows the block it made; ATTSYNC gives every reference to a block the attributes its definition now has, keeping their values, adding new ones at their defaults and removing the ones no longer defined.
