- M2-71 (#343): Dynamic Input keeps keys typed ahead of their prompt: every key typed before the drawing's engine has read the last input waits, at the command line and in the tooltip alike, and goes into the fields of the prompt it reaches, so `-VIEW` `S` `Two words` typed fast into the tooltip saves `Two words` and `LINE` `5,5` `10,0` typed at once draws from 5,5 to 15,5. A comma after a number in Dynamic Input's Distance field now switches to X and Y relative to the last point, as AutoCAD's pointer input reads a second point, and an Esc typed behind waiting keys cancels after them.
