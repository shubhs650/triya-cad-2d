- M5-03 part 4 (#552): Insert Field comes to the attribute dialogs. ATTDEF's Default, BATTMAN Edit Attribute's Default and EATTEDIT's Value each have an Insert Field button (and Ctrl+F) that opens the Field dialog and puts the field where the caret is; the field shows by its value, is edited as one piece, and a double click on it opens it again to change it. A block whose default holds a field gives it to every reference that takes the default, a value typed over a field keeps just the text, and ATTSYNC keeps each reference's own fields.
