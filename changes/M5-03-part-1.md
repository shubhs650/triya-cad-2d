- M5-03 part 1 (#525): ATTDEF (alias ATT) opens the Attribute Definition dialog: the Mode check boxes (Invisible, Constant, Verify, Preset, Lock position, Multiple lines), Tag, Prompt and Default (a multiline default edited in the In-Place Text Editor), the insertion point typed or picked on screen, and the text settings (justification, style, height, rotation, boundary width, each pickable on screen); Align below previous attribute definition stacks the next one under the last. -ATTDEF asks the same at the command line, and ATTDISP switches attribute display between Normal, ON and OFF. Each is one undo step and saves to DXF.
