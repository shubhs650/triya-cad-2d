- M1-105 (#203): DXF validity gate: the required CI job saves every readable public corpus file as AC1032 DXF, unedited and edited, and loads each save with ezdxf `recover` + `audit` (CI only); nothing may be reported except what ezdxf reports on the source file too (`scripts/dxf-audit/exceptions.json`, with reasons) or a verified ezdxf limitation, and a save with a dangling owner handle must fail. The gate found two save bugs, fixed in acad-ts: ATTRIB/ATTDEF were written with a second AcDbText subclass, so other readers dropped every attribute (patch 0170), and a visibility parameter read from DWG was written as `92 NaN` (patch 0171).
