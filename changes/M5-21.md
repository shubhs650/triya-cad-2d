- M5-21 (#584): text typed after a click elsewhere during TEXT is no longer lost. The click moved the in-place line editor but took the keyboard from it, and keys typed while the engine was still placing the line before were held and handed to the editor while the command line kept the focus, so the next Enter ended TEXT at the command line and the new line was never placed (seen on CI in `text-edit.spec.ts`). The line editor now keeps the focus through a click on the canvas, as AutoCAD's does, and takes it back whenever it is handed held keys; a test delays the engine's replies so the keys are held every run.
