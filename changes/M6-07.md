- M6-07 (#614): the Layer Properties Manager gains AutoCAD's Plot Style and VP Plot Style columns. In a drawing with named plot styles they open Select Plot Style to set a layer's plot style or override it in the layout viewport made current (VPLAYER gains PStyle); the override is saved as the layer's `ADSK_XREC_LAYER_PLOTSTYLE_OVR` record (DEC-078) and plotted. A colour-dependent drawing shows the colour's plot style, greyed.
