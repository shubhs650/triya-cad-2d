- M9-03 part 2 (#651): dimensional constraints in the solver: Horizontal, Vertical (Linear picks one), Aligned (two points, point and line, a line's length, two lines made parallel), Angular (two lines, an arc, three points), Radial and Diameter, each value a Parameters Manager parameter (d1, ang1, rad1, dia1…) driven by expressions. Changing a value moves the second object the way a drafter expects (along its direction, or turning about the vertex) and is refused, nothing changed, when the geometry cannot take it; reference constraints measure and follow the geometry. The commands and the Parameters Manager palette come in later parts.
