- M9-03 part 3 (#655): dimensional constraint commands. DIMCONSTRAINT and DCLINEAR, DCHORIZONTAL, DCVERTICAL, DCALIGNED, DCANGULAR, DCRADIUS and DCDIAMETER (also on the Parametric tab's new Dimensional panel) put a value on a distance, angle, radius or diameter: pick the objects or points, place the dimension line, then type a value, `name=expression`, or press Enter to keep what is measured. The geometry moves to the value, the second object adjusting; a value that would over-constrain the drawing is offered as a reference constraint. Dimensional constraints are saved with the drawing (DEC-082) and still hold when it is opened again. Showing them on the drawing and the Parameters Manager palette come next.
