- M5-02 part 3 (#529): editing block references in place. REFEDIT picks a reference and opens the Reference Edit dialog (the reference and the ones nested in it under the pick, all of its objects or only those picked, attribute definitions shown or not, the rest of the drawing locked or not); -REFEDIT asks the same at the command line. The block's objects are carried out where the reference draws them and edited in place with every command, objects drawn meanwhile joining them, under the Edit Reference bar. REFSET moves objects in and out of the working set; REFCLOSE Save carries them back into the block, so every reference shows the edits and what was not edited stays exactly as it was, and Discard takes every change back. REFEDITNAME names the block being edited.
